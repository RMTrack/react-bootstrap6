## Example

Use the `striped`, `bordered` and `hover` props to customise the table.

<CodeBlock language="jsx" live>
  {TableBasic}
</CodeBlock>

## Small Table

Use `size="sm"` to make tables compact by cutting cell padding in half.

<CodeBlock language="jsx" live>
  {TableSmall}
</CodeBlock>

## Dark Table

Bootstrap 6 has no `.table-dark`. Render the table in the dark color mode with
`data-bs-theme="dark"` to get light text on a dark background. To color a table
with a theme color, use the `variant` prop, which applies a `.theme-*` class.

<CodeBlock language="jsx" live>
  {TableDark}
</CodeBlock>

## Striped rows

Use `striped` to add zebra-striping to any table row within the table.

## Striped columns

Use `striped="columns"` to add zebra-striping to any table column.

## Responsive

Responsive tables allow tables to be scrolled horizontally with ease.

### Always Responsive

Across every breakpoint, use `responsive` for horizontally scrolling tables.
Responsive tables are wrapped automatically in a `div`. The following example
has 12 columns that are scrollable horizontally.

<CodeBlock language="jsx" live>
  {TableResponsive}
</CodeBlock>

### Breakpoint specific

Use `responsive="sm"`, `responsive="md"`, `responsive="lg"`, `responsive="xl"` or `responsive="2xl"`
as needed to create responsive tables up to a particular breakpoint. From that
breakpoint and up, the table will behave normally and not scroll horizontally.
`responsive="md"` renders a `.md:table-responsive` wrapper.

<CodeBlock language="jsx" live>
  {TableResponsiveBreakpoints}
</CodeBlock>

## Stacked

Use the `stacked` prop to show each row as a block on narrow containers, with the header
row hidden visually. Pass a breakpoint to stack only below it: `stacked="md"` renders
`.md:table-stacked`. Label the cells with a `data-cell` attribute, which Bootstrap shows
above each value.

Stacked tables use a container query, so a parent must be a query container, for example
`.contains-inline`. Make your browser window narrower to see the example stack.

<CodeBlock language="jsx" live>
  {TableStacked}
</CodeBlock>
