## Content types

### Body

Use `<Card.Body>` to pad content inside a `<Card>`.

<CodeBlock language="jsx" live>
  {CardBodyOnly}
</CodeBlock>

Alternatively, you can use this shorthand version for Cards with body
only, and no other children

<CodeBlock language="jsx" live>
  {CardBodyShorthand}
</CodeBlock>

### Title, text, and links

Using `<Card.Title>`, `<Card.Subtitle>`, and
`<Card.Text>` inside the `<Card.Body>` will line them up nicely. In
Bootstrap 6, `.card-title` and `.card-text` are unstyled hooks: the
`.card-body` is a flex column that spaces its children with a gap.

Bootstrap 6 removed `.card-link`, so `Card.Link` was removed too. Use plain
links, and flex or gap utilities to line them up next to each other.

`<Card.Text>` outputs `<p>` tags around the content, so you can
use multiple `<Card.Text>`s to create separate paragraphs.

<CodeBlock language="jsx" live>
  {CardText}
</CodeBlock>

## Images

Cards include a few options for working with images. Choose from
appending “image caps” at either end of a card, overlaying images with
card content, or simply embedding the image in a card.

### Image caps

Similar to headers and footers, cards can include top and bottom “image
caps”—images at the top or bottom of a card.

<CodeBlock language="jsx" live>
  {CardImageAndText}
</CodeBlock>

### Horizontal

Add `.card-row` to lay a card out horizontally, and use `<Card.Img variant="start">`
(or `"end"`) for an image on the side.

<CodeBlock language="jsx" live>
  {CardHorizontal}
</CodeBlock>

### Image Overlays

Turn an image into a card background and overlay your card’s text.
Depending on the image, you may or may not need additional styles or
utilities.

<CodeBlock language="jsx" live>
  {CardImgOverlay}
</CodeBlock>

## Card Styles

### Theme colors

The `bg` prop applies a theme color with `.theme-*`, which colors the card's border.
Use the `text` prop to set a text color with `.fg-*`.

<CodeBlock language="jsx" live>
  {CardBgColor}
</CodeBlock>

### Subtle

Add `variant="subtle"` (`.card-subtle`) to tint the header, footer and borders with the
theme color. `variant="translucent"` (`.card-translucent`) renders a frosted, see-through
card for use over images or colored backgrounds.

<CodeBlock language="jsx" live>
  {CardSubtle}
</CodeBlock>

### Border Color

<CodeBlock language="jsx" live>
  {CardBorder}
</CodeBlock>

## Card layout

### Card Groups

Card groups use a container query, so the cards only sit side by side when a parent
is a query container. Add `.contains-inline` to a parent, as in the example below.

<CodeBlock language="jsx" live>
  {CardGroup}
</CodeBlock>

### Grid cards

Use `Row`'s [grid column](../layout/grid#setting-column-widths-in-row) props to control how many cards to show per row.

<CodeBlock language="jsx" live>
  {CardGrid}
</CodeBlock>
