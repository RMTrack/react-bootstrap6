## Overview

Here’s what you need to know before getting started with the Navbar:

- Use the `expand` prop to allow for collapsing the `Navbar` at lower breakpoints.
  `expand="lg"` renders `.lg:navbar-expand`.
- Below the `expand` breakpoint, the navigation goes in a `<Navbar.Drawer>`,
  opened by `<Navbar.Toggle>`. Bootstrap 6 has no collapsing navbar, so
  `Navbar.Collapse` was removed.
- The navbar is a CSS query container, so `expand` responds to the navbar's own width,
  not the viewport's. A navbar inside a narrow column stays collapsed.
- `Navbar`s and their contents are fluid by default. Use optional
  [containers](#containers) to limit their horizontal width.
- Use spacing and flex utilities to size and position content

A responsive navigation header, including support for branding, navigation, and more.
Here’s an example of all the sub-components included in a responsive navbar that
automatically collapses into a drawer below the md (medium, 768px) breakpoint.

<CodeBlock language="jsx" live>
  {NavbarBasic}
</CodeBlock>

## Color schemes

Bootstrap 6 removed `.navbar-light` and `.navbar-dark`. A navbar follows the page's
color mode, and `variant` scopes one with `data-bs-theme`: `variant="dark"` renders
`data-bs-theme="dark"`. Set the surface with the `bg` prop, which adds a `bg-*`
utility. The neutral surfaces `bg="1"` and `bg="2"` are common choices, as is any theme
color or custom css.

<CodeBlock language="jsx" live>
  {NavbarColorSchemes}
</CodeBlock>

## Containers

While not required, you can wrap the Navbar in a `<Container>` component
to center it on a page, or add one within to only center the contents of a
[fixed or static top navbar](#placement).

<CodeBlock language="jsx" live>
  {ContainerOutside}
</CodeBlock>

When the container is within your navbar, its horizontal padding is removed at
breakpoints lower than your specified `expand={'sm' | 'md' | 'lg' | 'xl' | '2xl'}`
prop. This ensures we’re not doubling up on padding unnecessarily on lower
viewports when your navbar is collapsed.

<CodeBlock language="jsx" live>
  {ContainerInside}
</CodeBlock>

## Placement

You can use Bootstrap's <DocLink path="/utilities/position/">position utilities</DocLink> to
place navbars in non-static positions. Choose from fixed to the top, fixed to the bottom, or
stickied to the top (scrolls with the page until it reaches the top, then stays there), or
stickied to the bottom (scrolls with the page until it reaches the bottom, then stays there).

Fixed navbars use `position: fixed`, meaning they’re pulled from the normal flow of the DOM and may
require custom CSS (e.g., padding-top on the `<body>`) to prevent overlap with other elements.

Since these positioning needs are so common for navbars, we've added convenience props for them.

### Fixed top

```jsx
<Navbar fixed="top" />
```

### Fixed bottom

```jsx
<Navbar fixed="bottom" />
```

### Sticky top

```jsx
<Navbar sticky="top" />
```

### Sticky bottom

```jsx
<Navbar sticky="bottom" />
```

## Responsive behaviors

Use the `expand` prop as well as the `Navbar.Toggle` and `Navbar.Drawer` components to control
when content collapses behind a button. Above the breakpoint, the drawer's contents are laid out
inline in the navbar.

Set the `defaultExpanded` prop to make the Navbar start with its drawer open. Set `collapseOnSelect`
to close the drawer automatically when the user selects an item. You can also finely control
the behavior by using the `expanded` and `onToggle` props.

:::caution

Watch out! You **need** to provide a breakpoint value to `expand` in order for the Navbar to collapse at all.

:::

<CodeBlock language="jsx" live>
  {NavbarCollapsible}
</CodeBlock>

### Drawer

`Navbar.Drawer` accepts the `Drawer` props, such as `placement`, so you can choose which
edge the drawer slides in from.

In the example below, to create a drawer navbar that is always collapsed across all breakpoints,
set the `expand` prop to `false`.

</CodeBlock>
