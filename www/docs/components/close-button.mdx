## Disabled state

Bootstrap adds relevant styling to a disabled close button to prevent user
interactions.

<CodeBlock language="jsx" live>
  {CloseButtonDisabled}
</CodeBlock>

## Variants

Bootstrap 6 draws the close icon with a CSS mask over `currentcolor`, so the button
follows the current text color. The `variant="white"` prop (`.btn-close-white`) was
removed. For a light close button, render it in the dark color mode with
`data-bs-theme="dark"` on a parent, or set the color with a `.fg-*` utility.

<CodeBlock language="jsx" live>
  {CloseButtonVariants}
</CodeBlock>

## Accessibility

To ensure the maximum accessibility for Close Button components, it is
recommended that you provide relevant text for screen readers. The example
below provides an example of accessible usage of this component by way of the
`aria-label` property.

<CodeBlock language="jsx" live>
  {CloseButtonLabelled}
</CodeBlock>
