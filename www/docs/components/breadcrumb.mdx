## Example

Add `active` prop to the active `Breadcrumb.Item`. Do not set both `active` and `href` attributes. `active` overrides `href` and `span` element is rendered instead of `a`.

<CodeBlock language="jsx" live>
  {Breadcrumb}
</CodeBlock>

Bootstrap 6 renders the separators as explicit `.breadcrumb-divider` items between
the `.breadcrumb-item`s, and links get `.breadcrumb-link`. `Breadcrumb` adds the
dividers for you. An empty divider shows Bootstrap's default chevron.

## Dividers

Use the `divider` prop to put text or an icon in each divider.

<CodeBlock language="jsx" live>
  {BreadcrumbDivider}
</CodeBlock>
