## Native HTML5 form validation

For native HTML form validation–[available in all our supported browsers](https://caniuse.com/#feat=form-validation),
the `:user-invalid` and `:user-valid` pseudo selectors are used to apply validation
styles as well as display feedback messages.

Bootstrap 6 scopes these styles to a parent with the `data-bs-validate` attribute,
usually the `<Form>`. The `validated` prop is a shortcut: `validated` renders
`data-bs-validate`, and `validated="valid"` renders `data-bs-validate="valid"` to also
show the success styles on valid controls.

Because `:user-invalid` only matches once the user has interacted with a control or
tried to submit the form, required fields no longer show up as invalid on page load.
Bootstrap 6 has no `.was-validated` class, and the `validated` prop no longer adds one.

:::caution Watch out!

Browsers provide their own validation UI by default on `form`s. You can disable the
default UI by adding the HTML `noValidate` attribute to your `<Form>` or `<form>` element.

:::

<CodeBlock language="jsx" live>
  {ValidationNative}
</CodeBlock>

## Form libraries and server-rendered styles

It's often beneficial (especially in React) to handle form validation
via a library like Formik, or react-formal. In those cases, `isValid`
and `isInvalid` props can be added to form controls to manually apply
validation styles. Below is a quick example integrating with
[Formik](https://github.com/jaredpalmer/formik).

<CodeBlock language="jsx" live>
  {ValidationFormik}
</CodeBlock>

## Tooltips

If your form layout allows it, you can use the `tooltip` prop to display
validation feedback in a styled tooltip (`.tooltip.invalid-tooltip`). Be sure to have a parent with
`position: relative` on it for tooltip positioning. In the example below,
our column classes have this already, but your project may require an
alternative setup.

<CodeBlock language="jsx" live>
  {ValidationTooltips}
</CodeBlock>

## Input group validation

Bootstrap 6 removed `.has-validation`, and the `hasValidation` prop was removed with it.
Instead, place the feedback after the `<InputGroup>`, inside an element with the
`.form-field` class. Bootstrap shows it when a control in the group is invalid.

<CodeBlock language="jsx" live>
  {ValidationInputGroup}
</CodeBlock>
